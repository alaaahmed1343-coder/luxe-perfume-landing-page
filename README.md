# LUXÉ | Luxury Perfumes

A modern and elegant Luxury Perfume Landing Page designed to showcase premium fragrances and provide a sophisticated user experience.

## Live Demo

[LUXÉ | Luxury Perfumes](https://alaaahmed1343-coder.github.io/luxe-perfume-landing-page/)

## About The Project

LUXÉ is a responsive luxury perfume website featuring a modern dark and gold visual identity.

The website includes:

* Hero Section
* About LUXÉ Section
* Luxury Services
* Customer Feedback Carousel
* Fully Responsive Design
* Responsive Navigation Bar
* Footer with Social Media Links

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* Vanilla JavaScript
* Google Fonts
* Font Awesome
* Bootstrap Carousel

## Features

* Fully responsive across different screen sizes
* Smooth hover effects and animations
* Fixed navigation bar with scroll effect
* Bootstrap responsive grid system
* Customer testimonials carousel
* Modern luxury UI design
* Organized and reusable CSS
* Local assets and Bootstrap files
